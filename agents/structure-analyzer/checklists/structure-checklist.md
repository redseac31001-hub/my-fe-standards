# 项目结构检查清单

> 用于 Structure Analyzer Agent 的检测规则说明

## 检测规则详解

### SA001: 按类型分组（Type-Grouped）

**严重度**: ⚠️ Warning

**检测逻辑**:
- 检测顶层目录是否按文件类型分组
- 匹配模式：`components/`, `views/`, `store/`, `utils/`, `hooks/`, `services/`, `helpers/`, `api/`

**智能豁免**:
1. **白名单豁免**：`components/`, `shared/`, `common/`, `assets/` 等通用目录不报警
2. **结构检测**：仅当项目存在 `features/` 目录时才报警
3. **规模阈值**：目录内文件数 < 10 时不报警

**问题说明**:
按类型分组会导致：
- 相关代码分散在不同目录
- 功能变更需要跨多个目录修改
- 难以独立开发和测试功能模块

**改进建议**:
```
❌ 反模式
src/
├── components/    # 所有组件
├── views/         # 所有页面
├── store/         # 所有状态
└── utils/         # 所有工具

✅ 推荐模式
src/
├── features/
│   ├── user-profile/
│   │   ├── components/
│   │   ├── store/
│   │   └── api/
│   └── shopping-cart/
│       ├── components/
│       ├── store/
│       └── api/
└── shared/        # 真正的共享代码
```

---

### SA002: 目录过深嵌套（Deep-Nesting）

**严重度**: ⚠️ Warning

**检测逻辑**:
- 目录嵌套深度超过阈值（默认 5 层）
- 从 `src/` 开始计算

**问题说明**:
过深嵌套会导致：
- 导入路径过长，难以阅读
- 模块定位困难
- 可能存在职责划分不清

**改进建议**:
- 考虑扁平化目录结构
- 将深层模块提取为独立功能
- 使用路径别名简化导入

---

### SA003: 巨型文件（Giant-File）

**严重度**: 🔴 Error

**检测逻辑**:
- 文件行数超过阈值（默认 500 行）
- 或文件大小超过阈值（默认 100KB）

**问题说明**:
巨型文件会导致：
- 难以理解和维护
- 测试困难
- 容易产生合并冲突
- 违反单一职责原则

**改进建议**:
- 按职责拆分为多个小模块
- 提取公共逻辑到工具函数
- 将组件拆分为子组件

---

### SA004: 命名相似度过高（Similar-Naming）

**严重度**: ⚠️ Warning

**检测逻辑**:
- 同一目录下的文件/目录名称相似度超过阈值（默认 80%）
- 使用 Levenshtein 算法计算相似度
- 性能防护：限制比较对数（默认 50 对/目录）

**问题说明**:
相似命名会导致：
- 容易混淆和误用
- 代码审查时难以区分
- 可能存在重复实现

**示例**:
```
⚠️ 相似命名
├── user.ts
├── users.ts
├── userInfo.ts
└── user-info.ts
```

**改进建议**:
- 使用更具区分度的命名
- 考虑合并相似模块
- 建立命名规范

---

### SA005: Feature 模块越权（Feature-Violation）

**严重度**: ℹ️ Info

**检测逻辑**:
- 检测 `features/*/internal/` 目录
- 提示确保其他 feature 不直接引用此目录

**问题说明**:
Feature 模块越权会导致：
- 模块间耦合度增加
- 难以独立开发和测试
- 违反模块边界原则

**改进建议**:
- 使用公共导出接口（index.ts）暴露必要的 API
- 将共享代码移至 `shared/` 目录
- 通过事件或依赖注入解耦

---

## 评分算法

```
基础分 = 100

featureStructure = 25 - (SA001数量 × 5)，最低 0
depth = 25 - (SA002数量 × 5)，最低 0
fileSize = 25 - (SA003数量 × 10)，最低 0
naming = 25 - (SA004数量 × 5) - (SA005数量 × 1)，最低 0

总分 = featureStructure + depth + fileSize + naming
```

## 评分解读

| 分数范围 | 健康度 | 建议 |
|----------|--------|------|
| 90-100 | 优秀 | 继续保持 |
| 70-89 | 良好 | 逐步改进 |
| 50-69 | 一般 | 建议重构 |
| 0-49 | 较差 | 急需改进 |
