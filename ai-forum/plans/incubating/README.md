# 孵化计划目录

> 本目录用于存放**有想法但暂不执行**的计划方案。

---

## 目录用途

| 状态 | 说明 |
|------|------|
| **孵化中** | 有初步想法，待讨论或待资源 |
| **待激活** | 方案成熟，等待排期执行 |
| **已归档** | 决定不执行或已被其他方案替代 |

---

## 与正式计划的区别

| 目录 | 用途 | 状态管理 |
|------|------|----------|
| `plans/*.md` | 已批准、正在执行的计划 | 🟢 已批准 → 🔵 执行中 → ✅ 已完成 |
| `plans/incubating/*.md` | 孵化中的想法和方案 | 💡 孵化中 → 🟢 已激活（移至上级目录） |

---
