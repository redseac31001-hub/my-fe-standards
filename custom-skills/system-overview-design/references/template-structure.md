# 系统概要设计模板结构

源模板：`docs/系统概要设计模版.docx`

## 模板识别结论

- 模板类型：章节样式模板，不是占位符模板
- 正文层级样式：
  - 一级标题：`heading 1`
  - 二级标题：`heading 2`
  - 三级标题：`heading 3`
  - 正文：`正文内容`
- 目录位于正文前，最终导出后需要在 Word 中手动刷新目录字段

## 模板内置表格

### 封面元信息表

主要字段：

- 文档名称

- 保密级别
- 文档版本号
- 制作人 / 制作日期
- 复审人 / 复审日期

### 版本控制表

列：

- 版本
- 日期
- 参与人员
- 更新说明

### 系统接口清单表

- 序号
- 接口序号
- APIKIT序号
- 接口
- 公司外访问

- 接口描述
- 发起方

## 使用约束

- 没有图形文件时，图类章节先输出图例说明、节点关系和绘制要求，不要伪造图片。
- 缺接口字段、容量指标、部署域时，不要编造数值；在交付说明中标记待补充。
- 当前脚本保留模板封面、目录和样式，并从正文一级标题开始重建内容。
